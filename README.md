# دعوة زفاف محمد و طيبة

موقع دعوة زفاف تفاعلي — ست شاشات (الغلاف، الدعوة، الموعد، المكان،
تأكيد الحضور، الختام) بألوان فاتحة وفرحة. مبني بـ HTML/CSS/JS بسيط
بلا أي مكتبات خارجية — يفتح مباشرة بأي متصفح.

## الملفات
- `index.html` — الصفحة الرئيسية (كل الشاشات الست)
- `style.css` — الألوان والخطوط والحركة
- `app.js` — كل المنطق (التنقّل، العدّاد، التقويم، تأكيد الحضور، الأمنيات)
- `config.js` — **الملف الوحيد الذي تحتاجين تعديله عادة** (الأسماء، التاريخ، المكان، الروابط)
- `audio/` — مكان ملف الأغنية (فاضي حالياً، التفاصيل بـ `audio/README.txt`)
- `img/` — لأي صور تُضاف لاحقاً

## ١. أضيفي الأغنية (اختياري)
اقرئي `audio/README.txt` — بسبب حقوق الملكية ما قدرت أرفق ملف
الأغنية نفسه. الموقع يعمل تمام بدونها، فقط بدون موسيقى.

## ٢. عدّلي البيانات
افتحي `config.js` وعدّلي فقط القيم بين علامتي التنصيص إذا تغيّر أي
شيء (التاريخ، المكان، رابط الأغنية...). لا تلمسي بقية الملفات إلا
إذا تريدين تغييرات بالتصميم نفسه.

## ٣. رفعه على GitHub Pages
1. أنشئي مستودع (Repository) جديد على GitHub، مثلاً باسم `wedding-mt`.
2. ارفعي كل ملفات هذا المجلد إلى المستودع (اسحبيها بصفحة "Add file → Upload files" أو عبر git).
3. من إعدادات المستودع Settings → Pages، اختاري:
   - Source: **Deploy from a branch**
   - Branch: **main** (أو master) والمجلد **/(root)**
4. احفظي، وانتظري دقيقة أو اثنتين. الرابط يظهر أعلى نفس الصفحة
   بشكل: `https://username.github.io/wedding-mt/`
5. لإرسال رابط شخصي باسم كل ضيف، أضيفي بنهاية الرابط:
   `?guest=اسم-الضيف` — مثال:
   `https://username.github.io/wedding-mt/?guest=أحمد`

## ٤. تأكيد الحضور وأمنيات الضيوف (اختياري لكن يُنصح به)
بدون هذه الخطوة، كل رد أو أمنية تُحفظ على جهاز الضيف نفسه فقط ولا
تصلكم. لجعلها تصلكم جميعاً بجدول واحد:

1. أنشئي Google Sheet جديد بعمودين (أو أكثر حسب الحاجة).
2. من القائمة Extensions → Apps Script، الصقي كود بسيط يستقبل
   POST ويضيف صفاً جديداً بالجدول (يمكن البحث عن "Apps Script web
   app receive POST Google Sheet" لأي دليل جاهز، الفكرة قياسية).
3. انشري الكود كـ **Web App** (Deploy → New deployment → Web app)
   مع صلاحية "Anyone" حتى يقدر أي ضيف يرسل بياناته.
4. انسخي رابط الـ Web App الناتج وحطيه في `config.js`:
   - `rsvpEndpoint` لتأكيد الحضور
   - `wishesEndpoint` للأمنيات (يمكن استخدام نفس الرابط بجدول ثانٍ، أو رابط منفصل)

هذا الجزء تقني نوعاً ما — إذا احتجت مساعدة بكتابة كود Apps Script
نفسه، اطلبيه وأكتبه لك جاهزاً للّصق.

## ملاحظات
- التوقيت مضبوط على توقيت بغداد (UTC+3) بشكل ثابت داخل الكود، حتى
  يبقى العدّاد صحيحاً حتى لو فتح الدعوة أحد أقاربكم من خارج العراق.
- الموقع يحترم خاصية "تقليل الحركة" بالهاتف/الحاسوب لمن يفعّلها.
- لا حاجة لأي تثبيت أو بناء (build) — الملفات تُفتح كما هي.
